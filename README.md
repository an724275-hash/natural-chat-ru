# natural-chat-ru

Компактный скилл для русскоязычного общения и переписки. Автор: Артём Назаров / ave dev.

По умолчанию: короткие прямые ответы, строчные начала предложений, понятная неформальная пунктуация. Это выбранная манера речи, не универсальное определение хорошего текста и не детектор ИИ.

## Область применения

Ответы в чате, переписка, разговорные объяснения и сообщения о ходе работы. Не меняет стиль кода, интерфейсов, договоров, резюме и других документов. Сообщение в TXT остаётся перепиской, договор в чате остаётся документом. Прямая просьба писать официально важнее разговорного пресета.

Нет инструментов, внешних сервисов, исполняемых скриптов или зависимости от antislop. Примеры читаются только при необходимости. Более приоритетные инструкции приложения сохраняют силу; ускорение не гарантируется.

## Установка в Codex

1. Скопируйте только папку `skills/natural-chat-ru/` в личный каталог скиллов. При настроенном `CODEX_HOME` используйте его подкаталог `skills`; иначе обычный путь: `~/.codex/skills` (Windows: `.codex/skills` внутри вашего профиля). Проверьте расположение скиллов, поддерживаемое вашей версией приложения.
2. Начните новую сессию и убедитесь, что `natural-chat-ru` доступен. Для явного вызова напишите `$natural-chat-ru` и запрос.
3. Чтобы применять стиль по умолчанию, добавьте отмеченный блок из [шаблона подключения](integration/AGENTS.snippet.md) в действующие личные инструкции. Замените placeholder на реальный абсолютный путь к установленному SKILL.md. Не заменяйте весь существующий AGENTS.md. Проверьте AGENTS.override.md: при его наличии он может иметь приоритет. Если отмеченный блок уже есть, обновите его, не добавляйте второй.
4. Начните новую сессию. Спросите, какие инструкции стиля загружены, затем проверьте обычный ответ без названия скилла. Самоотчёт модели является подсказкой, не доказательством загрузки: если приложение показывает фактически подключённые инструкции или журнал их загрузки, проверьте их тоже. Наличие папки и один стилистически подходящий ответ сами по себе не гарантируют применение на каждом ходу.

У другого агента используйте его документированный каталог скиллов и механизм постоянных инструкций. Этот пакет сам ничего не устанавливает в другие приложения.

[Официальная документация Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md) объясняет приоритет инструкций. Правила проекта или явный запрос могут переопределять глобальные предпочтения.

## Настройка под себя

Меняйте раздел `Voice preset` в SKILL.md: регистр, пунктуацию, обращение и допустимость мата. Можно оставить обычные заглавные буквы или отказаться от скобок. Блок глобальных инструкций только ссылается на скилл, поэтому настройки не нужно повторять в двух местах.

При необходимости добавьте отдельную приватную справку о себе с условием читать только для соответствующих задач. Не публикуйте её вместе с личными переписками, контактами и данными заказчиков. Выберите одну версию голоса по умолчанию: публичную или личную, не обе сразу.

## Отключение

Чтобы оставить только явный вызов в Codex, удалите отмеченный блок natural-chat-ru из действующих инструкций и в установленном `agents/openai.yaml` смените `policy.allow_implicit_invocation` на `false`. Сохраните остальные поля и правила. Одного удаления блока недостаточно: скилл всё ещё может выбираться автоматически.

Для полного отключения после проверки личных дополнений удалите только установленную папку natural-chat-ru и её отмеченный блок. Начните новую сессию. В другом приложении используйте его настройку отключения автоматического выбора; если такой настройки нет, уберите установленный скилл из обнаруживаемого каталога. Не удаляйте родительский каталог скиллов или весь профиль агента.
